Taski

Taski is a Flutter-based task management application designed to help users organize, track, and manage their daily tasks efficiently.

Features

* 📝 Create and manage tasks
* ✅ Mark tasks as completed
* ⭐ Mark important tasks
* 🗑️ Move deleted tasks to the recycle bin
* 🔔 Task reminders
* 🎨 Customizable themes and colors
* 🔐 Firebase Authentication
* ☁️ Firebase Firestore for data storage

Tech Stack

* Flutter
* Dart
* Firebase Authentication
* Cloud Firestore
* GetX
* SharedPreferences
